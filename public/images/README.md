# Hotel Website Image Assets Directory

All frontend images for **Mahendra Hotel** are mapped to this directory (`public/images/`).
You can simply copy your photos directly into the folders below or replace the paths with your own Supabase Storage/CDN URLs in `src/data/images.ts`.

---

## Folder & File Structure Guide

### 1. Hero Slides (`public/images/hero/`)
Recommended aspect ratio: `16:9` or `1920x1080`
- `hero-1.jpg` – Main exterior / hotel entrance facade photo
- `hero-2.jpg` – Reception counter / lobby check-in desk
- `hero-3.jpg` – Deluxe guest room / suite photo

### 2. About Us (`public/images/about/`)
Recommended aspect ratio: `4:3` or `800x600`
- `lobby.jpg` – Clean lobby & comfortable seating area
- `service.jpg` – Friendly reception staff / hospitality service

### 3. Rooms (`public/images/rooms/`)
Recommended aspect ratio: `4:3` or `1200x800`
- **Deluxe AC Room**:
  - `deluxe-ac-main.jpg`
  - `deluxe-ac-1.jpg`
  - `deluxe-ac-2.jpg`
- **Executive Family AC Room**:
  - `family-ac-main.jpg`
  - `family-ac-1.jpg`
  - `family-ac-2.jpg`
- **Standard Non-AC Room**:
  - `standard-non-ac-main.jpg`
  - `standard-non-ac-1.jpg`
  - `standard-non-ac-2.jpg`

### 4. Nearby Attractions (`public/images/attractions/`)
Recommended aspect ratio: `4:3` or `800x600`
- `mahalaxmi-temple.jpg` – Shri Ambabai Mahalaxmi Temple
- `jyotiba-temple.jpg` – Jyotiba Temple
- `panhala-fort.jpg` – Panhala Fort
- `rankala-lake.jpg` – Rankala Lake
- `newPalace.jpg` / `new-palace.jpg` – Chhatrapati Shahu Museum / New Palace

### 5. Gallery Photos (`public/images/gallery/`)
Recommended aspect ratio: `4:3` or `800x600`
- `gallery-1.jpg` through `gallery-9.jpg`

---

> **Note:** If an image file is not yet added to a folder, the website automatically displays an elegant, branded **"Photo Pending"** fallback card so your website never displays broken links or blank boxes.
